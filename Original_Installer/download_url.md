# Download the Armada Online client installer

Download the Armada Online alpha client installer from the [Armada Online Alpha Installer page on ModDB](https://www.moddb.com/games/armada-online/downloads/armada-online-alpha-installer).

The installer listing is dated **October 4, 2012**. The download filename is `armadaonlinealpha.msi`.

Run the installer to install the game, then follow the setup instructions in [README.md](../README.md) to copy the patched client and connect to the local emulator.
